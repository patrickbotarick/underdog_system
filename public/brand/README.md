# Asset oficial pendente

Adicionar aqui a logo original autorizada pelo proprietário, preferencialmente SVG ou PNG transparente. Registrar a origem e a autorização de uso antes de incluí-la na interface. Nenhuma marca substituta foi criada. O nome do projeto é exibido como texto comum até a entrega do arquivo.

Os ícones neutros em `public/icons/` são identificadores técnicos provisórios da PWA, não a identidade oficial da barbearia. Substituí-los por exportações autorizadas antes de homologar a publicação.
